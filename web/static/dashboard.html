Пуск, темп и Dry Run

Пока включён DRY_RUN, агент смотрит и решает, но палец в приложение не вставляет — безопасный режим для первой настройки.

Коннект и нейросеть

Панель пересобирает коннект по частям: сначала поднимается новое подключение, прежнее закрывается только после успеха. Не вышло — воркер остаётся на старом канале.

# Architecture

Карта системы. Код: `agents/` (LLM-бэкенды), `scripts/` (конфиг, фабрика,
платформенные драйверы), `tests/`.

## Поток решения

```
run_android.py / run_ios.py / run_mac.py      (платформенный драйвер)
        │  uiautomator2 | Appium
        ▼
скриншот + bio анкеты ──► agent (base.py)
        │  vision-запрос + правила: лайк только при уверенности > LIKE_THRESHOLD
        ▼
agent_factory (AGENT env: claude | openai | gemini | custom)
        ▼
решение: LIKE / SKIP ──► драйвер выполняет свайп ──► пауза DELAY_MIN..DELAY_MAX
```

## Ключевые решения и их причины

1. **Порог уверенности в base.py + env** (`LIKE_THRESHOLD`, дефолт 75):
   инвариант «ни одного лайка без уверенного решения» проверяется один раз,
   в базовом классе — бэкенды не могут его обойти.
2. **Фабрика агентов** (`agent_factory` + `AGENT` env): бэкенды LLM сменяемы
   без правки цикла; `custom_agent.py` — легальная точка расширения.
3. **Все секреты через env** (`scripts/config.py`, dotenv): ключи LLM не
   попадают в код и логи; `LIKE_THRESHOLD`/`MAX_SWIPES`/`DELAY_*` тоже env —
   тюнинг без правки кода.
4. **Три отдельных run-скрипта**: платформы требуют разной подготовки
   (uiautomator2 vs Appium), отдельный файл на платформу нагляднее флагов.
5. **Сетевой-guard в pytest.ini**: тесты не обращаются наружу даже случайно —
   LLM и драйверы мокаются.

## Инварианты
- Лайк ставится только при уверенности выше порога.
- Цикл не падает на нестандартных анкетах.
- Ключи LLM не покидают окружение.

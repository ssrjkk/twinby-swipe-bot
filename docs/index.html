Подбор анкет, который думает за вас

Агент смотрит на фото и bio глазами vision-модели, сверяет с вашими критериями и лайкает только те анкеты, где совпадение выше 75%. Остальное пропускает — без бесконечного свайпа.

Возможности

Не автокликер, а разбор каждой анкеты

Каждая анкета проходит через AI-анализ, а не через случайный свайп. Решение принимается по содержимому, а не по порядку в ленте.

Vision-анализ

Скрин анкеты и bio уходят в модель с зрением: агент видит фото и читает текст, а не угадывает по одной кнопке.

Порог 75%

Лайк ставится только при уверенности выше 75%. Всё, что ниже, агент пропускает — лента не засоряется случайными совпадениями.

Три платформы

Android через uiautomator2, iPhone и Mac через Appium (iOS Simulator). Один агент — разные устройства.

Мультиагентность

Claude, OpenAI GPT-4o, Gemini или ваш собственный агент. Провайдер выбирается под задачу и бюджет.

Свой агент за 3 шага

Интерфейс агента расширяемый: добавить нового провайдера можно тремя шагами, не переписывая ядро.

CI на трёх Python

GitHub Actions гоняет тесты на Python 3.10, 3.11 и 3.12 — регрессии ловятся до релиза.

Запуск

Свой агент за пару минут

Python-пакет с подключаемым провайдером. Клонируете, ставите зависимости, выбираете модель — и агент готов к работе.

Python 3.10+ uiautomator2 Appium Claude GPT-4o Gemini pytest
terminal
$ git clone https://github.com/ssrjkk/twinby-swipe-bot
$ cd twinby-swipe-bot
$ pip install -r requirements.txt
# выбираете провайдера и критерии в конфиге
$ python -m twinby_bot
